## Reproduce

Start the app in one terminal, then run:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe tests/integration_check.py --live-chat
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
$env:PLAYWRIGHT_BROWSERS_PATH = Join-Path (Get-Location) '.cache\playwright'
.\.venv\Scripts\python.exe -m playwright install chromium
.\.venv\Scripts\python.exe tests/browser_check.py
.\.venv\Scripts\python.exe tests/browser_mobile_check.py
.\.venv\Scripts\python.exe tests/browser_batch_check.py
```

Integration and browser chat checks make requests using GROQ_API_KEY. Unit tests use controlled clients and do not need a cloud key or model downloads. Browser upload checks use the fixtures generated by integration_check.py. The optional `--batch-only` flag runs only batch ranking/export after the fixtures exist.
